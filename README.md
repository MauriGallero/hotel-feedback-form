# Hotel Feedback Form

Formulario de feedback para hotel construido con HTML semántico y CSS moderno. Proyecto del curriculum de freeCodeCamp - Responsive Web Design.

### 🔗 Live Demo
https://MauriGallero.github.io/hotel-feedback-form/

### ✨ Features
- Estructura 100% semántica (`header`, `main`, `fieldset`, `legend`)
- Formulario totalmente accesible (labels conectados con `for` / `id`)
- Validación nativa HTML5 (`required`, `type="email"`, `min/max`)
- Inputs: text, email, number, radio, checkbox, select, textarea
- Diseño responsive y minimalista
- Listo para conectar a backend con `method="POST"`

### 🛠️ Tecnologías
- HTML5
- CSS3 (sin frameworks)

### 📂 Estructura
hotel-feedback-form/
├── index.html
├── styles.css
└── README.md



### 🚀 Cómo correrlo
Solo abrí `index.html` en tu navegador. No necesita instalación.

### 📚 Qué practiqué
Lo más útil de HTML en el mundo laboral: formularios complejos, accesibles y bien validados. Base para logins, checkouts y dashboards.
